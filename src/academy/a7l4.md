## Pourquoi cet atelier

La leçon « Ajouter l'IA dans une automatisation » t'a montré le principe : **l'automatisation transporte, l'IA comprend et rédige**. Ici, tu le vois à l'écran, étape par étape. On construit une automatisation qui, à chaque demande de devis reçue, **fait rédiger un brouillon de réponse personnalisé par l'IA** et te l'envoie par e-mail pour relecture.

Résultat : quand tu ouvres ta boîte, la réponse est déjà écrite. Tu relis, tu ajustes, tu envoies. Deux minutes au lieu de quinze.

> **L'humain garde la main** : l'IA rédige un **brouillon** qui arrive chez toi, pas chez le client. C'est la règle du feu orange du module 1.

## Ce que tu vas construire

**Formulaire de devis → Rédiger la réponse avec l'IA (+ modèle OpenAI) → Envoyer le brouillon à l'équipe**

![1 · Le workflow : le formulaire, l'étape IA avec son modèle branché en dessous, puis l'e-mail](/formation/captures/w3-01-workflow.webp)

Remarque la petite **bulle ronde sous l'étape IA** : c'est le **modèle de langage** (ici OpenAI). Dans n8n, l'étape IA est la « chaîne » qui prépare la consigne, et le modèle est un **sous-nœud** que tu peux changer à tout moment (OpenAI, Anthropic Claude, Google Gemini, Mistral…) sans toucher au reste.

## Étape 1 · Le déclencheur

Reprends le formulaire de devis de l'atelier du module 6 (ou duplique ce workflow). N'importe quel déclencheur fonctionne : un e-mail reçu, une nouvelle ligne dans un tableur, un message sur ton site…

## Étape 2 · Ajouter l'étape IA

Clique sur le **+** après le formulaire. Le menu propose une catégorie **AI** : agents, résumés, classement de textes, extraction d'informations.

![2 · Le menu des étapes : la catégorie « AI » en premier](/formation/captures/w3-02-menu-noeuds.webp)

Pour rédiger un texte à partir d'une consigne, le plus simple est **Basic LLM Chain** (« chaîne de modèle de langage simple »).

![3 · Rechercher « Basic LLM Chain »](/formation/captures/w3-03-recherche-llm.webp)

**Les autres étapes IA utiles** :

| Étape n8n | À quoi elle sert | Exemple |
|---|---|---|
| **Basic LLM Chain** | Rédiger, reformuler, résumer à partir d'une consigne | Brouillon de réponse, légende Instagram |
| **Text Classifier** | Ranger un texte dans une catégorie | « Devis », « SAV », « Facture », « Spam » |
| **Information Extractor** | Sortir des informations précises d'un texte | Nom, date, montant dans un e-mail |
| **Sentiment Analysis** | Détecter le ton | Avis client positif ou négatif |
| **Summarization Chain** | Résumer un long document | Compte rendu, contrat |
| **AI Agent** | Laisser l'IA choisir et utiliser des outils | Consulter l'agenda et proposer un créneau |

## Étape 3 · Écrire la consigne (le prompt)

Ouvre l'étape IA. Deux zones comptent :

1. **Prompt (User Message)** : la demande, avec les **données du formulaire** insérées par expressions (`{{ $json['Prénom'] }}`, `{{ $json.Besoin }}`…). Comme dans l'atelier 1, glisse les champs depuis la gauche.
2. **Chat Messages → System** : le **rôle et les règles** de l'IA, toujours les mêmes. C'est ici que tu colles ton prompt métier du module 4.

![4 · La consigne : les données de la demande (en haut) et le rôle de l'IA (message « System », en bas)](/formation/captures/w3-04-config-chaine.webp)

Le message System utilisé dans l'atelier :

> « Tu es l'assistante commerciale d'une agence de communication du Golfe de Saint-Tropez. Tu rédiges des réponses chaleureuses, professionnelles et courtes (150 mots maximum), en vouvoyant le client. Tu remercies, tu reformules le besoin, tu poses 3 questions utiles pour établir le devis et tu proposes un appel de 15 minutes. Tu n'inventes jamais de prix. »

> La dernière phrase compte : sans elle, l'IA pourrait annoncer un tarif. **Écris noir sur blanc ce que l'IA ne doit jamais faire.**

## Étape 4 · Brancher le modèle et ta clé API

Clique sur le **+ Model** sous l'étape IA et choisis ton fournisseur, par exemple **OpenAI Chat Model**. Choisis le modèle (un modèle « mini » ou « small » suffit largement pour rédiger un e-mail et coûte très peu) et une **température basse** (0,3 à 0,5) pour des réponses régulières.

![5 · Le modèle : le compte, le modèle choisi et la température](/formation/captures/w3-05-config-modele.webp)

La première fois, crée l'identifiant : la fenêtre demande ta **clé API**.

![6 · La fenêtre de connexion OpenAI : il suffit de coller ta clé API](/formation/captures/w3-06-cle-api-openai.webp)

**Où trouver ta clé API** :
- **OpenAI** : platform.openai.com → API keys → Create new secret key.
- **Anthropic (Claude)** : la console développeur Claude (Claude Platform) → API Keys.
- **Google (Gemini)** : aistudio.google.com → Get API key.
- **Mistral** : console.mistral.ai → API Keys.

> **Attention** : l'API est **facturée à l'usage**, séparément de ton abonnement ChatGPT ou Claude. Pour ce type de brouillon, compte généralement **moins d'un centime par e-mail** avec un petit modèle. Fixe une **limite de dépense mensuelle** dans la console du fournisseur, et ne partage jamais ta clé.

## Étape 5 · Envoyer le brouillon

Ajoute **Send Email** (ou Gmail → « Create a draft », encore mieux : le brouillon apparaît directement dans ta boîte, prêt à envoyer). Le texte de l'IA se trouve dans `{{ $json.text }}`. Pour reprendre des informations du formulaire, deux étapes plus tôt, on écrit `{{ $('Formulaire de devis').item.json.Entreprise }}` : n8n le fait pour toi quand tu glisses le champ.

![7 · L'e-mail : l'objet reprend l'entreprise, le texte contient la réponse de l'IA](/formation/captures/w3-07-config-email.webp)

## Rendre la réponse fiable

- **Donne du contexte** : colle dans le message System tes offres, ton ton, tes délais (sans les prix si tu ne veux pas qu'ils sortent).
- **Demande un format** : « Commence par une ligne Objet : », « 150 mots maximum », « pas d'émoji ».
- **Teste avec des cas difficiles** : un message vide, un message en anglais, une demande hors sujet. Ajuste la consigne jusqu'à ce que les trois donnent un résultat correct.
- **Relis toujours** avant d'envoyer, au moins le premier mois.
- **Données personnelles** : n'envoie à l'IA que ce qui est utile pour répondre, et vérifie les conditions de ton fournisseur (module 1).

## Les mêmes réglages dans Make et Zapier

| Dans n8n | Dans Make | Dans Zapier |
|---|---|---|
| Basic LLM Chain + OpenAI Chat Model | OpenAI → « Create a Completion » (ou Anthropic Claude, Gemini, Mistral) | ChatGPT (OpenAI) → « Conversation » ou AI by Zapier |
| Message System | Champ « Role : System » / « Instructions » | Champ « Instructions » ou « System Message » |
| Prompt avec expressions | Prompt avec variables glissées | Prompt avec données insérées |
| Credential OpenAI (clé API) | Connexion OpenAI (clé API) | Compte OpenAI connecté |
| Text Classifier | Module IA avec consigne « réponds uniquement par : … » + routeur | AI by Zapier → « Analyze and return data » + Paths |

## À retenir

- Une étape IA = **une consigne + des données** ; le **modèle** est un sous-nœud interchangeable.
- Le message **System** fixe le rôle et les interdits ; le **prompt** apporte les données de chaque demande.
- L'API se paie **à l'usage** : petit modèle, limite de dépense, clé jamais partagée.
- L'IA rédige un **brouillon** : c'est toi qui envoies.

## À toi de jouer (1 heure)

1. Choisis un message que tu écris souvent (réponse à une demande, remerciement après une prestation, demande d'avis).
2. Construis le workflow avec ton propre message System et teste-le sur **5 demandes différentes**.
3. Note ce qui ne te plaît pas dans les brouillons et ajoute une règle dans la consigne pour chaque défaut.
